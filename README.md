## 🎬 Features

- **Movie Search** – Search for movies by their titles.
- **Category Filters** – Explore movies by Action, Thriller, Animation, Horror, Mystery, Mind-Bending, Sci-Fi, and All categories.
- **Interactive Movie Cards** – Browse movies through a visually engaging card layout.
- **Movie Ratings** – View movie ratings alongside movie information.
- **Cinematic Hero Section** – A visually appealing hero section with a movie-inspired background.
- **Responsive Design** – Designed to provide a smooth browsing experience across different screen sizes.
- **Dynamic Rendering** – Display movie cards dynamically using JavaScript.

## 🎨 Design

CineVerse features a cinematic dark olive and black color palette with gold accents, creating a modern movie-browsing experience.

## 🎞️ Movie Content Attribution

Movie poster images and related movie content are sourced from [The Movie Database (TMDB)](https://www.themoviedb.org/).

This product uses the TMDB API but is not endorsed or certified by TMDB.
